# Azure Administrator M365 Integration

> PowerShell module for Azure and Microsoft 365 automation integration.

## Overview

This PowerShell project was extracted from an article on [MSEndpoint.com](https://msendpoint.com) and is part of the professional automation portfolio.

### Quick Start

```powershell
# Clone the repository
git clone https://github.com/Msendpoint/azure-administrator-m365-integration.git
cd azure-administrator-m365-integration

# One-click install & run (checks prerequisites, installs modules, launches main script)
.\Install.ps1
```
